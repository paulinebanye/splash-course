# Splash Course

A 3D obstacle-course runner built with three.js for [start.ng](https://start.ng).
Run through Big Balls, a Spinner, Sliders, a Balance Beam, Falling Tiles and the Finale.
Wipe out with style for points, grab the stars, and beat the clock. Your start.ng character is the runner.

- Side-on view. Run: D/→ (A/← back), step in/out: W/S or ↑/↓ (touch joystick on mobile) · Jump: Space (JUMP button on mobile) · Pause: P / Esc
- Leaderboard columns (see `startng.json`): Score (highest), Course time (lowest)
- Static site: no build step. three.js is vendored in `lib/`.
